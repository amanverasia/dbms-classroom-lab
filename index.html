ASK THE ROOM

Who should be able to delete all student records?

⚠
rootDatabase administrator
ALL PRIVILEGES
  • Read data
  • Add & change data
  • Delete tables
  • Create users

Powerful — never the website account.

◆
web_appApplication account
SELECT · INSERT · UPDATE
  • Read required data
  • Create records
  • Update records
  • Cannot drop tables

Only the permissions the app needs.

◎
reportingAnalyst account
SELECT ONLY
  • Read approved data
  • Build reports
  • Cannot change data
  • Cannot delete data

Useful access, limited risk.
